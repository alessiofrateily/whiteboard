# whiteboard
A simple virtual blackboard to write upon slides with pen or mouse

## Previewing the dashboard

Open the project directory in a terminal and launch a lightweight web server, then visit the page in a browser.

```bash
cd whiteboard
python3 -m http.server 8000
```

Navigate to <http://localhost:8000/wb.html> to interact with the dashboard layout and verify that all components render as expected.
